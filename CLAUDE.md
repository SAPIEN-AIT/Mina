# Mina — Berkeley Humanoid Lite Workspace

> Full-stack humanoid robotics: Isaac Lab RL training → sim-to-sim validation → real-robot deployment, with Docker containerization and HPC cluster support.

## Project Identity

- **Robot:** Berkeley Humanoid Lite — open-source, sub-$5K, 3D-printed humanoid
- **Paper:** [arXiv:2504.17249](https://arxiv.org/abs/2504.17249)
- **Framework:** NVIDIA Isaac Lab 2.3.2 + Isaac Sim 4.5.0 + RSL-RL (PPO)
- **Python:** 3.11 only (hard requirement from Isaac Sim)
- **Package manager:** uv (with custom NVIDIA and PyTorch indices)

## Key Source Files

### Task Environment Pipeline
- **Base env config:** `source/berkeley_humanoid_lite/berkeley_humanoid_lite/tasks/locomotion/velocity/velocity_env_cfg.py`
  - 2048 envs, 0.005s sim dt, flat terrain, contact sensors with 3-frame air-time history
- **Humanoid MDP:** `…/config/humanoid/env_cfg.py` — 21-joint obs/actions, decimation=8 (25 Hz policy)
- **Biped MDP:** `…/config/biped/env_cfg.py` — 12-joint (legs only), tighter velocity ranges, stricter orientation penalty
- **Rewards:** `…/mdp/rewards.py` — velocity tracking (exp kernel), action regularization, step encouragement, contact penalties
- **Agent (PPO):** `…/config/{humanoid,biped}/agents/rsl_rl_ppo_cfg.py` — [256,128,128] MLP, 6000 iterations, lr=1e-3 adaptive

### Training & Inference
- **train.py:** Creates gym env → RSL-RL PPO runner → trains → saves checkpoints every 100 iters
- **play.py:** Loads checkpoint → runs inference → exports JIT + ONNX → generates `configs/policy_latest.yaml` with full deployment params (joint kinematics, Kp/Kd, control frequencies)
- **play_mujoco.py:** Loads ONNX policy + YAML config → runs in MuJoCo at 25 Hz → logs to `debug/`

### Real Robot
- **rl_controller.py:** `TorchPolicy` / `OnnxPolicy` wrappers, `RlController` handles UDP state→action at 250 Hz
- **run_locomotion.py:** Main real-robot policy execution script
- **gamepad.py:** Joystick velocity command mapping

## Docker Architecture

### Two containers (image hierarchy)

```
nvidia/isaac-lab:2.3.2
  └── mina-isaaclab-base        (dev: live code sync, manual pip install)
        └── mina-bhl-training   (headless training, streaming, eval — code baked in)
```

Streaming reuses `mina-bhl-training` with runtime flag overrides. ROS2 inference uses `mina_desktop:jazzy`.

### Common commands (all from project root)

```bash
# First-time setup
./docker_mina/run.sh ngc-login && ./docker_mina/run.sh pull-base && ./docker_mina/run.sh build-all

# Daily development (live code sync, must pip install packages each time)
./docker_mina/run.sh dev

# Headless training (code baked in)
./docker_mina/run.sh train [task] [num_envs]

# Streaming visualization (use native Isaac Sim Streaming Client, NOT browser WebRTC)
./docker_mina/run.sh stream [checkpoint]

# Evaluation with video
./docker_mina/run.sh eval [task] [checkpoint]

# Rebuild after code changes
./docker_mina/run.sh build-training

# ROS2 policy inference
./docker_mina/run.sh ros-policy [config]
```

### Critical Docker rules
1. **Dev container needs manual package install every fresh start:**
   ```bash
   /isaac-sim/python.sh -m pip install -e /workspace/source/berkeley_humanoid_lite_assets -q
   /isaac-sim/python.sh -m pip install -e /workspace/source/berkeley_humanoid_lite -q
   ```
2. **Assets package must be installed BEFORE main package** (it's a dependency)
3. **Use `isaaclab -p` wrapper**, never plain `python3`, for Isaac Lab tasks
4. **`ENABLE_CAMERAS=1`** required for any video recording
5. **Browser WebRTC streaming is broken** in this Isaac Lab version — use the native Streaming Client
6. **Rebuild order matters:** base → training
7. **`network_mode: host`** — two containers binding same ports will conflict
8. **Container runs as root** — files in logs/ will be root-owned on host

## Reward Structure

**Tracking (positive):** `track_lin_vel_xy` (1.5, σ=0.5), `track_ang_vel_z` (0.75)
**Regularization (negative):** `action_rate_l2` (-0.001), `dof_torques_l2` (-2e-5), `dof_acc_l2` (-1e-7)
**Gait (positive):** `feet_air_time` (2.0 humanoid / 1.0 biped)
**Penalties:** termination (-10), orientation (-1 to -2), feet_slide (-0.1), undesired_contacts (-1), joint_deviation (-1 each)

## Deployment Pipeline

1. **Train:** `./docker_mina/run.sh train` → checkpoint in `logs/`
2. **Export:** `play.py` → `policy.onnx` + `policy.pt` + `policy_latest.yaml`
3. **Sim-to-sim validate:** `play_mujoco.py --config configs/policy_latest.yaml` (MuJoCo at 25 Hz)
4. **Deploy:** `rl_controller.py` loads ONNX, receives robot state via UDP, sends joint targets at 250 Hz
5. **Control frequencies:** 2000 Hz physics → 250 Hz motor control → 25 Hz policy inference

## HPC / Cluster Workflow (SLURM)

Files in `docker_mina/cluster/`. Converts Docker images to Singularity `.sif`, uploads to `/panfs`, submits SLURM jobs. See `hpc_workflow.md` for full guide.

```bash
# Push image to cluster
bash docker_mina/cluster/cluster_interface.sh push mina-isaaclab-base

# Submit training job
bash docker_mina/cluster/cluster_interface.sh job mina-isaaclab-base \
  --task Velocity-Berkeley-Humanoid-Lite-v0 --num_envs 4096
```

## Known Gotchas

- **`isaaclab: command not found`** — The base image creates a wrapper script (not symlink) at `/usr/local/bin/isaaclab` because `isaaclab.sh` resolves its path via `dirname $BASH_SOURCE`
- **`ModuleNotFoundError: berkeley_humanoid_lite_assets`** — Both packages must be installed; assets first
- **`get_checkpoint_path` picks wrong dir** — Non-timestamped sibling dirs confuse the "latest" lookup
- **Play doesn't record video** — Must call `env.reset()` (not `env.get_observations()`) before the loop
- **`obs_normalizer` attribute error** — Newer RSL-RL removed it; play.py uses `getattr(..., None)` guard
- **Root-owned files** — Containers run as root; use `docker run --rm -v /path:/data alpine rm -rf /data/target` to clean
- **Bash `!` in double quotes** — Use single quotes for inline Python in bash to avoid history expansion
- **`dump_pickle` import** — Removed in newer Isaac Lab; train.py has a local fallback

## Conventions

- All commands run from the **project root** (`/home/alex/dev/Mina`)
- Isaac Lab extensions: packages under `source/` installed as editable (`pip install -e .`)
- Config snapshots: `params/env.yaml` + `params/agent.yaml` saved with each training run
